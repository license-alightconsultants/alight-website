# PART 9 — SQLITE DATABASE

Use Prisma with SQLite.

Design normalized relational models for:

- AdminUser.
- Role.
- Permission.
- Session.
- Enquiry.
- EnquiryActivity.
- Product.
- ProductFeature.
- ProductImage.
- Service.
- Industry.
- CaseStudy.
- Blog.
- BlogCategory.
- Testimonial.
- ClientLogo.
- Job.
- JobApplication.
- SiteSetting.

Add:
- Foreign keys.
- Indexes.
- Unique constraints.
- Timestamps.
- Proper deletion rules.
- Database migrations.
- Seed data.

Important production requirements:

- Use persistent disk storage.
- Never use in-memory SQLite.
- Store the database outside temporary deployment directories.
- Configure the database location through environment variables.
- Document backup and restore procedures.
- Use a single controlled database writer strategy.
- Consider SQLite's write concurrency limitations.
- Keep a migration and recovery strategy.
